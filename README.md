# 🎭 AI Sentiment Analysis Dashboard

A Streamlit-based interactive dashboard for analyzing IMDB movie reviews with AI-powered sentiment analysis and a local chatbot for insights.

---

## 🛠 Features

- **Sentiment Analysis**: Classify reviews as Positive, Negative, or Neutral using VADER.
- **Visual Analytics**:  
  - Key Performance Indicators (KPIs) like total reviews, avg sentiment score, positive/negative ratio.  
  - Sentiment distribution overview with bar and pie charts.  
  - Advanced insights like sentiment trends over time and sentiment vs. review length.
- **Top Words Analysis**: Identify the most frequent words per sentiment.
- **Polarizing Reviews & Words**: Highlight the most positive/negative reviews and common polarizing words.
- **Interactive Chatbot**: Ask questions about the reviews dataset using a lightweight local LLM (`distilgpt2`).
